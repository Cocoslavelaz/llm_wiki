Problem Formulation Environment Modeling

為什麼 Agent 的不確定性本質上是一張圖？

單輪生成 (Single-Turn): 靜態點估計

• 無狀態轉移：$P(Y \mid X)$，輸出文字後生命週期即終結。
• 無外部交互：生成錯誤僅為事實幻覺，無實體副作用。
• 孤立評估：衡量 Softmax 熵即可反映事實記憶的信心。

自主 Agent: 圖狀決策過程 (POMDP Graph)

• 時序狀態圖：狀態轉移 $(s_t, a_t, o_{t+1}, s_{t+1})$ 形成執行有向圖。
• 不可逆副作用：資料庫抹除、金流交易、API 呼叫無法輕易回滾。
• 誤差複合傳遞：上游規劃錯誤直接污染下游觀察，引發連鎖崩潰。

🔍 核心設計動機：為什麼需要「檢查點（Inspection Gates）」？

在圖狀決策中，如果沒有在關鍵狀態設定門控機制，前一步的微小偏差將以指數級放大。我們必須在動作發射前、路徑分歧時、以及 Agent 訊息傳遞邊上佈設明確的檢驗守則。

Node Inspection A Format Gate: Free-Text

語義熵：自由語言輸出的等價群組檢查 (Kuhn et al., Nature 2024)

當節點輸出為自由自然語言時，透過語義空間的夏農熵消除「換句話說」的假性高熵。

$$ \mathcal{SE}(x) = -\sum_{c \in C} P(c \mid x) \log P(c \mid x) \quad \text{其中 } P(c \mid x) = \sum_{y_i \in c} P(y_i \mid x) $$
1 採樣展開

在溫度 $T > 0$ 下採樣生成 $K$ 個候選回覆 $\{y_1, y_2, \dots, y_K\}$。

2 雙向蘊涵聚類

以 NLI 模型檢驗：$y_i \equiv y_j \iff (y_i \models y_j) \land (y_j \models y_i)$，劃入 $C$ 個等價類。

3 檢查判定

若 $C=1$ 則 $\mathcal{SE}=0$（高度確定）；若 $C > 1$ 且機率分散，則標記該節點為高不確定性。

⚠️ 檢查陷阱：結構化 JSON 坍縮 (JSON Collapse)

當 Agent 輸出為 API 參數（JSON）時，NLI 模型往往將括號或微小語法差異判定為「互相蘊涵」，導致候選輸出強制坍縮為單一群組（$C=1$），錯誤報告低不確定性！

Node Inspection B Format Gate: JSON & Tools

語義發散度：結構化工具調用的幾何檢查 (Donaldson 2026)

為解決 JSON 坍縮，轉向「相對於已承諾行動點（Committed Action）」在連續空間中的推土機距離。

Wasserstein 距離形式化

將 Agent 已承諾步驟 $y_{t-1}^{(k)}$ 與重採樣之 $N$ 次候選分佈投影至嵌入空間，計算一階推土機距離（$\mathcal{W}_1$）：

$$ \mathcal{W}_1(P_{\text{commit}}, P_{\text{sample}}) = \inf_{\gamma \in \Pi} \mathbb{E}_{(u, v) \sim \gamma}[\|u - v\|_2] $$

直接反映決策分佈在該軌跡點周圍的幾何離散半徑，作為該節點的內在不確定性（Intrinsic Uncertainty, IU）。

Decision Gate Action Gating

行動門控：不確定性驅動的三階段安全轉移

三階段門控決策模型 (Three-Tier Policy)

在調用具外部副作用（Side-effect）的工具前，計算該步驟綜合不確定性 $U(a_t)$：

$$ \text{Route}(a_t) = \begin{cases} \text{Direct Execute}(a_t) & \text{if } U(a_t) < \tau_{\text{safe}} \\ \text{Seek Human Clarification} & \text{if } \tau_{\text{safe}} \le U(a_t) < \tau_{\text{crit}} \\ \text{Abort / Self-Reflect} & \text{if } U(a_t) \ge \tau_{\text{crit}} \end{cases} $$

• $\tau_{\text{safe}}$: 自主執行安全門檻（維持高自動化率）。
• $\tau_{\text{crit}}$: 嚴重風險警戒線，阻斷不可逆操作。

校準與評估指標體系

• ECE (Expected Calibration Error)：信心與經驗正確率之差距： $$ \text{ECE} = \sum_{m=1}^M \frac{|B_m|}{N} \left| \text{acc}(B_m) - \text{conf}(B_m) \right| $$ • AUARC (Accuracy-Rejection Curve)：衡量拒絕高不確定性樣本後，保留樣本準確率的提升幅度。
• PRR (Prediction Rejection Ratio)：標準化拒答收益，消除底層基準模型準確率的偏差。

Trajectory Paradox Progress Gate: 50% vs 100%

長程自主任務的不確定性動態：最後一步至關重要 (Li et al., 2026)

在深度研究（BrowseComp / HLE）等長程任務中，早期不確定性檢查能否有效預測成敗？

50% 進度檢查失靈

在 50% 軌跡進度時，所有主流 UQ 指標（Verbal Conf, PPL, Entropy, Max NLL）的 AUROC 均低於 0.60，幾乎與隨機猜測無異。

最終步信心突增

所有指標在 80%~90% 前極端微弱，唯有抵達終點時語言化信心急遽攀升至 0.85 AUROC。成功軌跡在終點信心躍升 15%，失敗軌跡則微跌 6%。

特徵聚合毫無助益

即便嘗試 Running Mean、Running Min 或使用 LightGBM 將 5 種不確定性特徵複合訓練，亦無法提升前中期的預測力。

$$\text{Trajectory AUROC at 50% Progress: } \text{Verbal Conf } (0.58), \text{ PPL } (0.54), \text{ Shannon Entropy } (0.53) \implies \text{早期信號失效}$$
Mechanistic Insight State Branching

為什麼早期檢查會失效？路徑切換動態 (Path Switching)

路徑切換現象 (Path Switching)

• 在長程搜尋中，Agent 頻繁在途中放棄當前線索並轉移方向（例如：*"Let me try a different search"*）。
• 普及率極高：BrowseComp 中有 86.8% 軌跡包含路徑切換，平均每條軌跡發生 8.5 次切換！
• 相關性斷裂：切換前的「低信心」反映的是即將被捨棄的局部死胡同，而非最終成敗。

Spearman 相關係數的動態演變

• 切換前 (Step $t-5 \to t-1$)：信心與最終正確性的相關度 $|\rho| < 0.15$（完全解耦）。
• 切換後 (Step $t+1 \to t+5$)：確立方向後，相關度單調上升至 0.30 ~ 0.50。
• 結論：早期不確定性不是失誤的預警，而是探索過程的自然表現！

🔍 任務性質的關鍵分水嶺：在唯讀（Read-only）的網頁檢索中，切換路徑成本為零；而在具備環境狀態變更的 Coding 任務（TerminalBench 2.0） 中，因為檔案被改動具備路徑依賴（Path-dependence），中間步驟 AUROC 即可維持在 0.66 ~ 0.78。

Transition Routing Retry Branching

Agent 骨架設計：中途干預 vs. 終點重試 (BrowseConf-Neg)

中途干預範式 (In-Trajectory: AUQ)

• 策略：每步監控信心，一旦低於門檻 $\tau = 0.8$ 即打斷 Agent 進行反思重擬計畫。
• 致命缺陷：
1. 早期信心判別力差，觸發大量假陽性（False Positives）。
2. 粗暴打斷 Agent 自身的路徑切換復原機制。
3. 反思過程額外消耗大量 token，在準確率-成本前沿上表現低劣。

終點重試範式 (Post-Completion: BrowseConf-Neg)

• 策略：放手讓 Agent 完整走完軌跡，僅在最終步驟檢查 Verbalized Confidence。
• 執行邏輯：若最終信心 $< 0.9$，則將「前次答案很可能是錯的」作為上下文否定提示，重啟新軌跡。
• 實證優勢：在相同 Step Budget 下，準確率全面 Pareto-Dominate 中途干預！

Multi-Agent Systems Interaction Topologies

多 Agent 系統 (MAS) 的可靠性困境：錯誤傳播與盲信

為什麼單 Agent UQ 在 MAS 中徹底失效？

• 局部自信，全域錯誤：下游 Agent 即使推理邏輯完全自洽，若輸入的上下文來自上游出錯的 Agent，下游依然會以「極高的局部自信」產出錯誤答案。
• 拓撲多樣性 (Topology Diversity)：MAS 包含串聯鏈式（Sequential）、星狀/層級式（Hierarchical）、去中心化網狀辯論（Decentralized Mesh）。單一模型 UQ 無法適應結構多樣性。

MAS 不確定性量化的核心追求
  • • 傳播感知 (Propagation-Aware)：必須追蹤錯誤如何在 Agent 之間遞迴傳導。
  • • 拓撲無關性 (Topology-Agnostic)：能無縫泛化至任意通訊結構。
  • • 線上可計算性 (Online Computability)：單次前向傳播即可逐步更新，支援及時截斷。
  • • 共識脆弱度度量：辨識看似一致但實則脆弱的集體盲從。
Propagation Gate 1 Recursive Rule

PropUQ-MAS：基於 DAG 的遞迴誤差傳播 (Liu et al., EMNLP 2026)

結構化誤差事件分解 (Error Decomposition)

將 MAS 執行歷史展開為有向無環圖 $\mathcal{G} = (\mathcal{V}, \mathcal{E})$。節點 $v$ 的整體失誤事件 $E_v$ 由局部推理失誤 $I_v$ 與上游污染事件 $Z_{pv}$ 共同構成：

$$ E_v = I_v \lor \left( \bigvee_{p \in \text{Pa}(v)} Z_{pv} \right) \quad \text{其中 } Z_{pv} = \mathbf{1}\{E_p = 1, M_{pv} = A\} $$

$M_{pv} \in \{A, C\}$ 代表採納（Acceptance）或批判（Critique）。批判不會產生新污染。

遞迴不確定性更新公式 (Recurrence Rule)

基於邊緣條件獨立與局部傳播獨立假設，節點 $v$ 的綜合不確定性 $r_v = \Pr(E_v = 1)$ 為：

$$ r_v = 1 - (1 - u_v) \prod_{p \in \text{Pa}(v)} (1 - \hat{\alpha}_{pv} r_p) $$

• $u_v$: 節點 $v$ 的局部單點不確定性。
• $r_p$: 父節點 $p$ 傳播而來的累積不確定性。
• $\hat{\alpha}_{pv} \in [0, 1]$: 下游對上游訊息的自我回報採納分數（Adoption Score）。

Propagation Gate 1 Error Blocking

PropUQ-MAS：批判阻斷機制與線性複雜度

性質 1: 有界性 (Boundedness)

若 $u_v, r_p, \hat{\alpha}_{pv} \in [0, 1]$，則嚴格保證 $0 \le r_v \le 1$。源節點自然退化為 $r_v = u_v$。

性質 2: 批判衰減 (Attenuation)

當下游具備嚴格批判能力（$\hat{\alpha}_{pv} \to 0$）或低局部不確定性時，下游客觀風險 $r_v < \max r_p$，誤差成功被阻斷！

性質 3: 線性複雜度 (Linear)

拓撲單次前向傳遞時間複雜度為 $\mathcal{O}(|\mathcal{V}| + |\mathcal{E}|)$，推論僅需 1~4 秒，支援逐步線上串流更新。

Propagation Gate 2 Tensor Decomposition

MATU：透過高階張量分解量化多 Agent 不確定性 (Chen et al., ACL 2026)

不規則張量建構 (Ragged Tensor)

• 為捕捉通訊多樣性，對同一問題進行 $N$ 次 MAS 重複執行。
• 將 Agent $k$ 於第 $j$ 次執行的變動長度步數 $T_{j,k}$ 透過輕量模型（Qwen3-Embedding-0.6B）編碼為嵌入矩陣 $E^{(j,k)} \in \mathbb{R}^{T_{j,k} \times d}$。
• 堆疊構成三維不規則張量 $\mathcal{X} = \{E^{(j,k)}\}$。

PARAFAC2 (CP-2) 語義共識分解

• CP-2 分解可在步長變動的條件下對齊潛在因子：

$$ \mathcal{X} \approx \sum_{r=1}^R \lambda_r u_r^{(1)} \otimes u_r^{(2)} \otimes u_r^{(3)} $$

• 低秩近似代表多 Agent 在多次運行中達成的跨軌跡語義共識。

Tensor Theory Consensus Audit

MATU：重建誤差作為語義變異數與 OOD 偵測

重建殘差即整體語義變異數

在統計理論中，群體變異數代表樣本偏離共識均值的平方距離 $\text{Var}(X) = \mathbb{E}[\|X - \mu\|^2]$。MATU 將整體不確定性定義為跨 Rank 的 Frobenius 重建損失：

$$ U = \sum_{R=1}^{R_{\max}} \|\mathcal{X} - \hat{\mathcal{X}}_R\|_F^2 $$

損失越高，代表不同執行的推理路徑越難以被少數低秩語義成分解釋，即協同共識脆弱度極高。

實證應用：動態 AnyMac 與 OOD 偵測

• 動態拓撲適用性：在動態決定下一個 Agent 的 AnyMac 架構中，傳統 SAUP 失效，MATU AUROC 達 0.69 ~ 0.71。
• OOD 異常檢測：輸入分佈偏移時，MATU 分數呈現乾淨的斷崖分離（In-distribution 0.13 vs. OOD 0.92，基準 SAUP 僅 0.29 vs. 0.46）。
• 模型路由：指導選擇最佳 Backbone（Qwen vs Llama vs Gemma），顯著拉高系統最終正確率。

  • • BrowseComp / HLE：20~80 步真實網路長程瀏覽與人類專家級難題。
  • • TerminalBench 2.0：命令列終端環境，驗證具副作用操作下的不確定性。
  • • GSM8K / MedQA / MBPP+：多 Agent 數學、醫學與代碼生成測試基準。
核心量化指標定義 (Mathematical Metrics)

• AUROC：非對稱排序品質，測試失誤步驟是否被賦予更高的不確定性。
• ECE (Expected Calibration Error)：信心值是否嚴格對齊實際經驗命中率。
• AUARC (Accuracy-Rejection Curve)：選擇性拒答策略下的準確率提升能力。
• PRR (Prediction Rejection Ratio)：標準化拒答收益：

$$ \text{PRR} = \frac{\text{AUC}_{\text{uq}} - \text{AUC}_{\text{rand}}}{\text{AUC}_{\text{oracle}} - \text{AUC}_{\text{rand}}} $$

• Brier Score：機率均方誤差 $\frac{1}{N}\sum (p_i - y_i)^2$，基準值為 0.25。

Future Frontiers Research Horizon

開放挑戰與未來研究前沿 (Open Frontiers)

01. 推論延遲與即時性

多輪採樣法（MATU, 40s+）精度高但延遲過大；單次傳遞（PropUQ, ~2s）依賴模型自評採納分數。未來方向在於輕量級線上驗證器（Tiny Verifiers）與投機採樣的不確定性結合。

02. 狀態持久性與動態干預

在純檢索任務中應放手讓 Agent 跑完（終點重試優於中途打斷）；但在 Bash / DB 等具備實體副作用的環境中，如何設計兼具「探索自由度」與「安全熔斷」的自適應門控？

03. 群體盲從與可信辯論

多 Agent 協同中普遍存在「從眾效應（Conformity）」：強勢但錯誤的上游容易帶偏弱勢下游。如何藉由形式化保證（如 Conformal Prediction）為多 Agent 系統提供確定性的覆蓋率安全界限？
